# KidGem decisions and sources

## Decisions already made
Working brand: KidGem. Primary users: Grades 1–8. Subjects: mathematics, logic, coding, algorithms, English, French and Bengali. Learning model: concept, play, practice and challenge with gradual progression. Repository-first development and an initial GitHub Pages demo. The site should be attractive, easy to navigate and clear about the next step.

## Defaults proposed by this pack
Vite/React/TypeScript; device-only demo followed by backend family beta; 12 complete first-milestone lessons; curriculum-agnostic skill graph; independent language levels; cosmetic rewards; no public child profiles, messaging, advertising or live AI in the first release. These are implementation defaults, not evidence of features already built.

## Owner decisions before production
Choose the first curriculum jurisdiction and markets, final domain and brand clearance, production provider and budget, educator and fluent-language reviewers, support contact, final media rights and any business model. Identify data/consent requirements from the actual design before collecting family data. These decisions do not block local demo construction. No legal policy in this pack should be represented as counsel-approved.
