# KidGem build pack

Working brand: KidGem. Tagline: Play. Learn. Grow.
Prepared for the founder and the developer using Claude. Planning edition, October 27, 2026.

## Purpose
Build an attractive, accessible learning portal for Grades 1–8: mathematics, logic and brain games, coding, algorithms, English, French and Bengali. Children follow a visible sequence, understand why they are learning something, receive useful feedback and revisit skills over time. Popularity is a goal to test, not an outcome a developer can guarantee.

## How to use this pack
1. Extract the ZIP and keep the Markdown files together in a `docs` folder in the project repository.
2. Read `KidGem_Project_Guide.docx` for the overview. The numbered Markdown files contain the detailed requirements.
3. Give Claude all the Markdown files, `sample_lesson.json` and `CLAUDE_MASTER_PROMPT.txt`. In a coding workspace, place them in the repository; in chat, attach them.
4. Paste the master prompt. It instructs Claude to build the first working milestone immediately, validate it and document remaining work.
5. Use the phase prompts from document 08 to continue. Require a working, tested result at each milestone.
6. Use document 07 to decide whether a milestone is actually complete. Do not describe a static demo as a finished production portal.

## Documents
- 01_PRODUCT_REQUIREMENTS.md — audience, scope, feature priorities and measurable behavior.
- 02_NAVIGATION_AND_DESIGN.md — routes, screen structure, visual system and accessibility.
- 03_PATHWAYS_AND_CURRICULUM.md — Grades 1–8 scope, prerequisites, progression and mastery.
- 04_CONTENT_AND_GAMES.md — lesson schema, game rules, examples and editorial workflow.
- 05_TECHNICAL_ARCHITECTURE.md — repository, persistence, database, authorization and deployment.
- 06_GROWTH_AND_OPERATIONS.md — discovery, pilot, measurement, content operations and launch.
- 07_ACCEPTANCE_AND_RELEASE.md — testable requirements and release gates.
- 08_CLAUDE_PHASE_PROMPTS.md — focused prompts for development and continuation.
- 09_DECISIONS_AND_SOURCES.md — assumptions, owner decisions and official references.
- CLAUDE_MASTER_PROMPT.txt — copy-ready implementation instructions.
- sample_lesson.json — one machine-readable lesson example, not a complete content library.

## Defaults that keep work moving
English is the first interface language; English, French and Bengali labels are supported from the start. Language study level is independent of school grade. The first release is a functioning local-progress demo on GitHub Pages. Production accounts and synchronized progress are a later milestone with a real backend. Curriculum is a proposed skills sequence, not certified alignment to a particular jurisdiction. All subject and grade paths can be visible, but only implemented and reviewed lessons may be labeled ready.
